How Canopy Works

                
            


            

                

                    Step 1: Region Selection

                    User draws a polygon on Google Satellite imagery via Leaflet.js. GeoJSON coordinates extracted for
                    downstream analysis.
                


                

                    Step 2: Land-Use Classification [OSINT]

                    Overpass API queries OpenStreetMap for land-use tags (farmland, building, water, highway) within the
                    bounding box. This drives NDVI proxy computation.
                


                

                    Step 3: NDVI Computation [Computed]

                    NDVI is estimated from OpenStreetMap land-use classification as an OSINT proxy —
                    not from actual satellite multispectral imagery. Thresholds: <0.2 bare/stressed, 0.2–0.5
                    moderate, >0.5 healthy dense vegetation.

                    Ref: Rouse et al. (1974), USGS NDVI documentation. Tucker
                        (1979), Remote Sensing of Environment.
                


                

                    Step 4: Weather Telemetry [Live API]

                    Open-Meteo API provides real-time temperature, humidity, sunshine duration, UV index, and 14-day
                    precipitation history for the exact coordinates. No API key required.
                


                

                    Step 5: Rule Engine [Heuristic]

                    Pest Risk, Nutrient Flags, Irrigation Needs, and Climate Resilience are computed via transparent
                    threshold rules:

                    • Pest Risk: IF humidity > 65% AND temp > 25°C AND NDVI < 0.45 THEN HIGH RISK

                    • Nutrient: Pseudo-NDRE = NDVI × 0.85; IF < 0.25 THEN Deficient

                    • Irrigation: IF temp > 32°C AND NDVI < 0.3 THEN CRITICAL
                


                

                    Step 6: AI Narrative Synthesis [LLM]

                    If primary backend is available, Gemini API receives the computed NDVI value and generates a
                    2-sentence plain-text agricultural diagnosis. If unavailable, rule-based fallback generates a
                    data-grounded analysis locally. Output is sanitized via DOMPurify before DOM injection.
                


                

                    Step 7: Multi-Signal Fusion [Novel]

                    NDVI proxy is cross-referenced against real 14-day rainfall data from Open-Meteo to
                    contextualize vegetation status. Temporal change detection uses a deterministic estimate (not real
                    historical imagery — requires Sentinel Hub API credentials for actual time series).
